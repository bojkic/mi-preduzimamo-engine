# Fontovi Jost i Mulish

Fontovi se isporučuju lokalno radi izbjegavanja mrežnog učitavanja pri posjeti stranici. Izvorni autori i puna SIL Open Font License 1.1 nalaze se u `JOST-OFL.txt` i `MULISH-OFL.txt`. Softverska AGPL licenca projekta ne zamjenjuje licence fontova.

Licence su preuzete iz sljedećih tačno označenih upstream verzija:

- Jost: https://raw.githubusercontent.com/google/fonts/392d8403c9bcff1bdb011c16a24b0d5436eb35d0/ofl/jost/OFL.txt
- Mulish: https://raw.githubusercontent.com/google/fonts/4fc2349f63644b20792e839849e0f7b418fedb9e/ofl/mulish/OFL.txt

WOFF2 datoteke uključuju odgovarajuće podskupove pisama za prikaz latinice i ćirilice. Njihove putanje i CSS deklaracije zadržane su u ovom izdanju.
